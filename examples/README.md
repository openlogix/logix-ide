# Examples

The examples Logix IDE offers in File > Examples, built into the app. Each
folder `<board>/<name>/` is a Logix project: its files and a `logix-ide.toml`
with the board and a one-line description.

They're maintained here, edited in place. Many started from
[Apio](https://github.com/FPGAwars/apio)'s examples. They're licensed under
MIT or the Apache License 2.0, at your option, like the rest of this
repository.
